# Vacancy Landing

## Назначение
Отдельное CV-портфолио Ивана Агошкова под вакансию AI-инженера (тестовое задание «лендинг»). Работа только в этой папке, основной CV и соседние проекты не меняются. Не опубликовано. Футера на странице нет.

## Источники
- Факты и цифры: `../llms-full.txt` (только чтение).
- Докки Studio: репозиторий Докки Studio (приватный) - `src/static/design.css`, `editor.css`, `studio-starters.js`. Визуальные токены холста (фон #101011, карточка #19191a, радиус 24, пилюли, цвета веток) сняты с локально запущенной Studio на временных данных.
- Докки: интерфейс мини-приложения (`../assets/dokky-app-screen.jpeg` как образец, на страницу не попадает).
- Докки App (бывший Кодди): README приватного репозитория Докки App.
- Главный референс подачи: https://www.apple.com/iphone-duo/ .

## Стек и ограничения
Статические HTML/CSS/JS-модули, без сборки, CDN и зависимостей. Шрифт: системный SF Pro, запасной Inter (локально). Все сцены собраны кодом на учебных данных, внешних вызовов нет. Страница RU, `noindex,nofollow`.

## Архитектура
- `demo-data.js` - чистая модель: `NODES` (с позицией L/C/R и рядом), `EDGES`, `buildRun(id)` (новые объекты, `data` и человеческие `notes` для чата), `INTRO_NODES`/`INTRO_EDGES`/`INTRO_RUN` для hero, `DOKKY_QUESTIONS`, `APP_FLOW`, `APP_DIFF`.
- `script.js` - модули initNav/Reveal/Intro/Gallery/Counters/Studio/Dokky/App/Copy. Hero - липкая сцена, состояние считается из прогресса прокрутки (`INTRO`). Запуски Studio, Докки и Докки App отменяются токеном. Studio: холст слева, панель справа (чат / JSON по шагам).
- `styles.css` - токены Apple и Studio, секции, брейкпоинты 1068 / 860 / 734, `prefers-reduced-motion`, вариант без JS.
